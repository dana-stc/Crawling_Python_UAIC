## Name: Crawling
#### ID:34 | Difficulty: B

Creati o aplicatie care permite utilizatorului sa urmareasca modificarile din anumite pagini
web. Paginile web vor fi salvate intr-o baza de date. Utilizatorul va avea posibilitatea sa
adauge, sa stearga sau sa modifice paginile web salvate. In momentul in care apare o
modificare pe una din pagini, userul va fi notificat printr-un email. Modificarile vor fi cautate
recursiv in pagina web.

INPUT: https://en.wikipedia.org/wiki/Web_crawler

OUTPUT: Pagina web a fost modificata.
